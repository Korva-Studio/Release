# Korva Releases

## Authority and production status

This public repository is a distribution surface, not the release authority. Korva API
owns immutable release/channel truth and Build Tools owns protected build/signing and
publication. No Milestone 8 source or production-like rehearsal authorizes a public
publication, channel move, withdrawal, or customer rollout; the repository remains
unchanged until a separately authorized production release.

Public download and update channel for Korva.

This repository intentionally contains release artifacts only. Source code lives in private Korva-Studio repositories.

Downloads are published through GitHub Releases.
